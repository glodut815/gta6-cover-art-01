Neon Vice Cover Studio turns any photo into GTA 6-style multi-panel poster cover art — drag to frame each panel, pick a Sunset, Neon, Vice or Noir grade, edit the bold poster caption, and export a PNG in square, portrait or wide post sizes. It runs fully offline in a desktop browser; photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/app/index.html — or open `app/index.html` directly from disk. Upload a photo (or try a sample), pick a layout, grade the colours, write your caption, and hit “Preview & export PNG”.

To build the entry output the way the grader does:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/cover-out node main.ts
```
